# 돈돗 DONDOT

> 돈의 점을 잇고, 내일을 키우다.

돈돗(Dondot)은 ‘돈을 돋우다’처럼 내 돈을 건강하게 키우고, 소득·지출·자산·목표라는 돈의 점(Dot)을 연결해 더 나은 재무의 선을 만들어 간다는 뜻을 담은 개인 재무설계 도구입니다.

## 서비스 소개
소득과 지출을 정리하고, 금융자산과 부채를 살펴보며, 재무목표와 실행 계획을 비교할 수 있습니다. 하나의 답을 강요하기보다 선택지에 따른 결과와 가정을 보여주어 사용자가 자신의 상황에 맞게 판단하도록 돕습니다.

## 주요 기능
- 월 소득·생활비·금융자산·대출 입력 및 현금흐름 요약
- 비상자금 및 주거자금 목표 설정
- 여러 상환·저축 대안 비교
- 소득 감소와 돌발 지출을 가정한 현금흐름 테스트
- 월별 실행 체크리스트와 계획 점검
- 입력 데이터 브라우저 저장

## 기술 구성
- React + Vite + TypeScript
- Recharts, lucide-react
- 재무 계산 엔진과 UI 분리
- 규칙 기반의 설명용 예비 평가이며 생성형 AI 연동은 구현되어 있지 않습니다.
- 실제 금융기관 연결이나 금융거래 기능은 없습니다.

## 로컬 실행
Node.js LTS 설치 후 프로젝트 루트에서 실행합니다.

\`\`\`bash
npm install
npm run dev
\`\`\`

## 테스트 및 빌드
\`\`\`bash
npm test
npm run build
\`\`\`

명령 결과를 실제로 실행해 확인하기 전에는 테스트 또는 빌드 성공으로 간주하지 않습니다.

## 예시 데이터와 한계
초기 화면은 기능을 보여주기 위한 가상 사례 값으로 시작합니다. 실제 이용 시 본인의 상황에 맞게 수정해야 합니다. 계산은 입력된 값과 단순 가정을 사용하므로 실제 금융기관의 이자 계산, 수수료, 계약 조건과 차이가 날 수 있습니다. 세금·제도·상품 관련 판단은 최신 공식 자료를 확인하고 필요하면 자격 있는 전문가와 상담해야 합니다.

## 재무설계 과정
돈돗은 IFPK의 재무설계 6단계 프로세스를 참고해 재무목표를 정리하고 실행 계획을 점검할 수 있도록 구성했습니다.

## 개발 원칙
1. 계산은 결정론적 코드로 수행하고 숫자를 임의로 생성하지 않습니다.
2. 입력 가정, 계산 결과, 한계와 근거를 구분합니다.
3. 여러 대안을 비교할 수 있게 하며 최종 선택은 사용자가 판단하도록 합니다.
4. 예시 데이터는 실제 고객 정보나 실증 결과처럼 제시하지 않습니다.
