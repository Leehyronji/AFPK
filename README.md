# 돈돗,DONDOT — AFPK 재무설계 지원 프로토타입

> 상태: 초기 프로토타입(v0.3 제안안). 사용자 최종 확인 및 공식 근거 검증 전.

## 목적
가상의 사회초년생이 학자금대출, 고금리 신용대출, 비상자금, 주거자금 목표 사이의 우선순위를 비교할 수 있도록 돕는 재무설계 지원 프로토타입입니다. 단일 답을 강요하기보다 여러 계획의 현금흐름·부채상환·목표 간 상충관계를 함께 보여주는 것을 목표로 합니다.

## 기술 구성
- React + Vite + TypeScript
- Recharts, lucide-react
- 재무 계산 엔진과 화면(UI)을 분리
- 현재 초안은 규칙 기반 예비 평가이며, 실제 생성형 AI 연동은 구현되지 않았습니다.
- 실제 금융기관 연결이나 거래 기능은 없습니다.

## 예시 고객 데이터
모든 수치는 설계·테스트를 위한 가상값입니다. 실제 고객 자료나 금융기관의 상환명세를 의미하지 않습니다.
- 월 실수령액: 280만 원
- 월 생활비: 165만 원(주거비·관리비 65만 원, 식비 40만 원, 공과금 10만 원, 교통비 8만 원, 통신비 6만 원, 보험료 12만 원, 생활용품·개인용돈 16만 원, 의료·구독·기타 8만 원으로 구성한 가상 지출표)
- 별도 기타 지출: 0원(생활비 항목과 중복되지 않도록 설정)
- 학자금대출 잔액: 600만 원, 가정 금리 연 2%
- 신용대출 잔액: 800만 원, 가정 금리 연 7%
- 비상자금 목표: (월 생활비 165만 원 + 약정 대출상환 70만 원) × 3개월 = 705만 원(본 사례의 설계 기준)
- 주거자금 목표: 5년 내 1,500만 원

모든 수치는 가상 사례용 제안 가정이며 실제 고객 자료가 아닙니다. 금융자산 400만 원은 비상자금 200만 원과 주거 목적 자산 200만 원으로 나누어 설정했습니다. 월 생활비 항목과 자산 배분은 제출 전 사례 가정으로 최종 확정하고, 대출 금리·상환액도 실제 계약이 아닌 계산용 가정임을 명시합니다. 이 가정에서 월 잉여자금은 45만 원입니다.

## 로컬 실행
Node.js LTS 설치 후 프로젝트 루트에서:

```bash
npm install
npm run dev
```

## 테스트 및 빌드
```bash
npm test
npm run build
```

위 명령의 성공 여부는 별도 실행 후 기록해야 합니다. 현재 저장소에 업로드된다고 해서 테스트 또는 빌드가 통과한 것은 아닙니다.

## 검토 전제와 한계
- 대출 이자는 월 단위 단순 근사 계산입니다. 실제 금융기관의 일수 계산, 상환일, 수수료 및 약정조건과 다를 수 있습니다.
- 수익률·세금·물가를 반영하지 않은 목표자금 계산은 단순 필요 저축액입니다.
- 공식 제도·세금·금융상품 정보는 제출 전에 해당 기관의 최신 원문으로 확인하고 출처와 확인일을 기록해야 합니다.
- 보고서와 AI 활용 기술서는 초안입니다. 최종 제출 형식 및 페이지 수를 별도로 확인해야 합니다.

## 폴더 구성
- `src/`: React 화면과 재무 계산 엔진
- `src/engine/*.test.ts`: 계산 로직 테스트 초안
- `docs/`: 계산 가정 및 보고서·AI 활용 기록 초안
- `reports/`: 제출물 초안(추가 예정)

## 개발 원칙
1. 계산은 결정론적 코드로 수행하고 AI가 숫자를 임의로 계산하게 두지 않습니다.
2. 입력 가정, 계산 결과, 한계와 근거를 구분합니다.
3. 대안 비교를 먼저 제공하고 최종 선택은 사용자가 판단하도록 설계합니다.
4. 허구의 고객 정보와 실증 결과를 실제 데이터처럼 제시하지 않습니다.
