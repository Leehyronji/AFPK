# 사례 기준표 v0.3 제안안

이 문서는 가상 고객 사례를 일관되게 구성하기 위한 제안이다. 실제 고객 정보가 아니며, 제출본에 반영하기 전 사용자가 최종 확정해야 한다.

| 항목 | 제안 기준 | 설명 |
|---|---|---|
| 고객 표기 | 고객 K씨 | 개인정보 오인 방지 |
| 연령·가구 | 만 29세, 미혼, 1인 가구 | 가상 설정 |
| 직업·소득 형태 | 민간기업 사무직, 월급 근로자 | 월 실수령액 고정 가정 |
| 거주 형태 | 월세 거주 | 현재 주거비 포함 |
| 주거 목표 | 5년 내 독립 주거 이전을 위한 임차보증금 등 1,500만 원 마련 | 투자 목표가 아닌 목적자금 목표 |
| 월 실수령 소득 | 280만 원 | 세후 금액 가정 |
| 월 생활비 | 165만 원 | 항목별 지출표 아래 참조 |
| 학자금대출 | 잔액 600만 원, 연 2% 가정, 월 약정상환 20만 원 | 실제 계약 조건 아님 |
| 신용대출 | 잔액 800만 원, 연 7% 가정, 월 약정상환 50만 원 | 실제 계약 조건 아님 |
| 금융자산 | 400만 원 | 비상자금 200만 원 + 주거 목적 자산 200만 원으로 가정 |
| 월 잉여자금 | 45만 원 | 280만 − 165만 − 20만 − 50만 |
| 비상자금 목표 | 705만 원 | (생활비 165만 + 약정상환 70만) × 3개월 |

## 월 생활비 항목별 지출표

| 항목 | 월 금액 |
|---|---:|
| 주거비·관리비 | 650,000원 |
| 식비 | 400,000원 |
| 공과금 | 100,000원 |
| 교통비 | 80,000원 |
| 통신비 | 60,000원 |
| 보험료 | 120,000원 |
| 생활용품·개인용돈 | 160,000원 |
| 의료·구독·기타 | 80,000원 |
| **합계** | **1,650,000원** |

생활비는 가상 항목을 중복 없이 합산한 것으로 설정한다. 앱의 별도 기타 지출은 0원으로 둔다. 소득은 세후 실수령액으로 가정했으므로 급여에서 공제되는 세금·4대 보험료를 다시 생활비에 더하지 않는다. 보험료 12만 원은 보험 가입 사실을 의미하지 않으며, 실제 보장내역·중복가입·보장 공백은 별도 확인 항목이다. 국민연금 등 공적연금 납입은 급여 공제에 반영된 것으로 가정하고, 별도 은퇴자산 규모는 미확인으로 표시한다.

## 비상자금 산식의 의미

비상자금 목표 705만 원은 월 생활비 165만 원과 월 약정 대출상환액 70만 원을 합한 235만 원의 3개월분이다. 이는 소득 중단 시 생활비뿐 아니라 약정상환을 유지할 필요를 고려한 이 사례의 보수적 기준이다. 모든 고객에게 적용되는 법정 기준 또는 공식적인 단일 권고액으로 표현하지 않는다.

## 금융설계상 미확인 사항과 처리

- 보험: 실제 보유 계약·보장·보험료 납입내역은 미확인. 보험료 가정만으로 충분한 보장이라고 결론 내리지 않는다.
- 은퇴·연금: 세후 소득에 공적연금 급여공제가 반영된 것으로 가정하되, 예상 연금액·퇴직연금·개인연금은 미확인으로 표시한다.
- 세금: 세후 월급을 사용하므로 월 현금흐름에서 소득세·4대 보험을 재차 차감하지 않는다. 연말정산 환급·추징, 세액공제 적용 여부는 자료 부족으로 별도 판단하지 않는다.
- 주거 목표: 임차보증금 등 독립 주거 이전 자금으로 설정한다. 실제 지역·주택유형·목표 보증금의 시장 적정성은 추가 자료가 필요하다.
- 금리·상환조건: 대출 금리와 월 납부액은 가정이며 실제 약정서, 변동금리, 중도상환수수료, 상환일 기준 일할이자는 미확인이다.
