# 계산 기준 v0.2

- 월 잉여자금 = 월 소득 − 필수 생활비 − 기타 지출 − 학자금 약정상환 − 신용대출 약정상환 = 400,000원(임시 입력값 기준).
- 순자산 = 금융자산 4,000,000 − 부채 14,000,000 = −10,000,000원.
- 비상자금 목표 = 필수 생활비 1,700,000 × 3 = 5,100,000원.
- 현재 비상자금 2,000,000원은 임시 가정, 부족액 3,100,000원.
- 주거자금 목표 15,000,000원, 기간 60개월, 다른 목적 자산 2,000,000원 가정; 필요 월 적립액 약 216,667원.
- 월 이자 = 기초잔액 × 연이율 / 12. 실제 일할이자·납부일·수수료·변동금리 미반영.
- A 비상자금 우선, B 신용대출 우선, C 병행형, D 주거자금 월 적립 후 잔여액을 신용대출에 추가 상환.
- 현재 앱의 추천은 생성형 AI 호출이 아닌 규칙 기반 예비 로직이다.
