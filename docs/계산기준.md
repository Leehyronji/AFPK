# 계산 기준 v0.3 제안안

> 모든 숫자는 가상 사례용 가정이다. 아래 고객 프로필과 지출표를 최종 확정한 뒤 보고서·앱·기술서에 동일하게 반영한다.

- 고객: 만 29세, 미혼·1인 가구, 민간기업 사무직 월급 근로자, 월세 거주.
- 월 실수령 소득: 2,800,000원.
- 월 생활비: 1,650,000원 = 주거비·관리비 650,000 + 식비 400,000 + 공과금 100,000 + 교통비 80,000 + 통신비 60,000 + 보험료 120,000 + 생활용품·개인용돈 160,000 + 의료·구독·기타 80,000.
- 위 생활비 항목은 중복 없이 합산한 사례 가정이다. 앱의 별도 기타 지출은 0원으로 설정한다.
- 학자금대출: 잔액 6,000,000원, 가정 연이율 2%, 월 약정상환 200,000원.
- 신용대출: 잔액 8,000,000원, 가정 연이율 7%, 월 약정상환 500,000원.
- 월 잉여자금 = 2,800,000 − 1,650,000 − 200,000 − 500,000 = 450,000원.
- 금융자산 4,000,000원, 그중 비상자금 2,000,000원·주거 목적 자산 2,000,000원으로 배분한 가정.
- 총부채 = 6,000,000 + 8,000,000 = 14,000,000원.
- 금융자산만 반영한 순자산 = 4,000,000 − 14,000,000 = −10,000,000원(비금융자산 미포함).
- 비상자금 목표 = (월 생활비 1,650,000 + 월 약정 대출상환 700,000) × 3 = 7,050,000원. 본 사례의 보수적 설계 기준이며 보편적 법정 기준이나 모든 고객에게 적용되는 공식 권고가 아니다.
- 비상자금 부족액 = 7,050,000 − 2,000,000 = 5,050,000원.
- 주거자금 목표 15,000,000원, 기간 60개월, 현재 주거 목적 자산 2,000,000원. 필요 월 적립액 = ceil((15,000,000 − 2,000,000)/60) = 216,667원. 수익·세금·물가 미반영.
- 대안 A: 추가 신용대출 상환 0원, 비상자금 450,000원, 주거자금 0원.
- 대안 B: 추가 신용대출 상환 450,000원, 비상자금 0원, 주거자금 0원.
- 대안 C: 추가 신용대출 상환 225,000원, 비상자금 225,000원, 주거자금 0원.
- 대안 D: 추가 신용대출 상환 233,333원, 비상자금 0원, 주거자금 216,667원.
- 대안별 월 배분 합계는 월 잉여자금 450,000원을 초과하지 않는다.
- 월 이자 = 기초잔액 × 연이율 / 12. 실제 일할이자·납부일·수수료·변동금리 미반영.
- 대안 비교는 배분액이 고정된 단순 시뮬레이션이다. 목표 달성 후 자동 재배분은 반영하지 않는다.
- 앱 추천은 생성형 AI 호출이 아닌 규칙 기반 예비 로직이다.
